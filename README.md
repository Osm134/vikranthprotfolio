# Runku Vikranth — Digital Marketing Portfolio

A new React + Vite portfolio website built from the supplied portfolio brief and resume content.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Personalization before publishing

- Replace the hero portrait placeholder with the supplied professional photograph when available.
- The resume download buttons point to `public/Runku_Vikranth_Resume.pdf`; replace this file with the final approved resume if you have a separately formatted original.
- Add a LinkedIn URL only after the correct public profile URL is supplied. No LinkedIn button is shown until then.
- The VJC report values are presented as reported; revenue is not claimed as independently audited or wholly ad-attributed.

## Stack

React, Vite, Framer Motion, Recharts, Lucide React, Simple Icons dependency, responsive CSS.
